Registrador de Hábitos Diarios
Nombre: HabitTracker
Descripción:
App para registrar hábitos (ej. beber agua, ejercicio) con recordatorios y gráficos de progreso.

Sensores: Acelerómetro (contar pasos), luz (modo nocturno automático).

Multimedia: Gráficos de progreso.

Base de Datos: SQLite (local) + Firebase (backup en la nube).

Chat: Grupos de apoyo (ej. "Dejar de fumar").

IA: Sugerencias de hábitos basadas en registros previos.

Extra: Notificación PUSH si el usuario no registra un hábito en cierto horario o recordatorios.
